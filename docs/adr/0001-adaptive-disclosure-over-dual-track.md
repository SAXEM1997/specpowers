# 用渐进披露瘦身，而不是加一条强模型轻量轨

specpowers 是已发布的技能组，正本经多轮评审累积到 review 657 行 + protocols 777 行，其中约 40–50% 是同一规则的重复陈述。模型能力增强后，自然的反应是仿照 comet 增加一条「强模型快轨」（只约束结果、放开过程）。我们选择不新增轨，而是把既有单轨改为「单一权威源 + 按需加载」：判定类规则与标记格式留在 SKILL.md 主体，执行细则下放到按时机加载的 refs。理由是新增轨会让发布面、入口路由与维护成本翻倍，而当前痛点的主因是重复而非约束过多（comet 自己的 Classic 轨仍保留完整阶段治理）。代价是每轮固定注入面只降约 30%（657→460 行），因为口径节与 5 个收敛触发条件的原文是不可下放的红线。
